# 🚀 TaskFlow – Full Stack Task Management System

TaskFlow is a full-stack SaaS-style task management application built as part of the Frontend Developer Internship assignment.

The application includes authentication, role-based access control, task management, user dashboards, and an admin system overview panel.

## ✨ Features

### 🔐 Authentication
- User Registration
- Login with JWT
- Protected Routes
- Persistent Authentication
- Secure Logout

### 👥 Role-Based Access Control
- User Role
- Admin Role
- Route-level Protection
- Admin-only APIs

### 📊 User Dashboard
- Personal Task Statistics
- Total Tasks
- Pending Tasks
- In-Progress Tasks
- Completed Tasks
- High Priority Tasks

### 🛠 Task Management
- Create Task
- Update Task
- Delete Task
- Filter by Status
- Search Functionality
- Pagination Support

### 🧑‍💼 Admin Dashboard
- View All Users
- Delete Users
- System-wide Task Statistics
- Admin-only Routes

### 👤 Profile Management
- Update Name
- Update Email
- Optional Password Update

### 🎨 UI / UX
- Clean SaaS-style layout
- Responsive Design
- Modern Tailwind UI
- Loading States
- Success & Error Feedback
